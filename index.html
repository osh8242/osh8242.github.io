01 / ABOUT

경력 요약

여러 고객사가 함께 쓰는 데이터 조회·가공 서비스를 만들면서, 성능 저하, 고객사별 데이터 분리, 오래 걸리는 작업의 상태 문제를 해결해 왔습니다.

요청을 그대로 처리하지 않고, 그 뒤의 구조부터 들여다보는 백엔드 개발자입니다. 복잡한 업무 규칙과 데이터 흐름을 Java/Spring 서비스로 구현합니다.

고객사별 데이터와 권한
요청한 고객사의 데이터 영역만 선택하고, 조회 전에 권한을 확인합니다.
오래 걸리는 작업
대용량 파일 생성과 데이터 가공을 일반 요청과 분리하고, 성공·실패·취소 상태를 관리합니다.
데이터 조회와 가공 개선
복잡한 조회 조건을 구조화하고, 데이터베이스와 분산 처리 환경에 맞게 변환·검증합니다.
외부 시스템 연동
저장소, 분석 엔진, AI 문서 도구를 연결하면서 변경 전 확인과 오류 처리를 설계합니다.
